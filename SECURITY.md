# Security Policy

## Reporting Security Issues

Please do not publish security vulnerabilities publicly before they are reviewed.

To report a security issue, open a private advisory on GitHub or contact the maintainer directly.

## Scope

This project is a local desktop utility. It creates temporary files only inside the selected scan target and does not intentionally write to raw disks.

## Safe Usage

- Do not scan drives containing your only copy of critical data.
- Review generated reports before sharing them because they may contain drive serial numbers, usernames, paths, or device metadata.
- Run downloaded releases only from the official GitHub repository.
